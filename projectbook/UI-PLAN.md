# Общие панели и создание объектов

Результат одобрен пользователем 24 октября 2026 для commit без push: компактная общая панель с иконками, единые крошки, создание документов/каталогов и History с выбором книги или документа. Темы, метаданные, History вложений и More остаются планом. Ниже сохранена исходная структура обсуждения; окончательная компоновка описана в разделе «Уточнение компоновки». Подтверждённый стенд и дерево ранее зафиксированы в `aa30d625`.

## Общая структура

1. Общая верхняя полоса на всех страницах: название книги/Home, поиск по содержимому, Recent changes, Files, переключатель System / Light / Dark. Files открывает корневой список и выполняет роль Sitemap. Admin добавлять при появлении реальных административных функций.
2. Слева над деревом: New document и New folder, затем Find in tree и управление раскрытием. Поиск дерева фильтрует пути; глобальный поиск ищет содержимое.
3. Справа: единые хлебные крошки, название и контекстная полоса с одинаковым расположением. Действия зависят от типа открытого объекта:
   - Markdown: Edit, History, Download; Rename/Delete в More.
   - Изображение/PDF/другое вложение: Open original, Download; History после подключения истории файлов; Rename/Delete в More после реализации безопасных обработчиков.
   - Каталог: список содержимого. Создание всегда доступно слева; Up и переходы к родителям через крошки.
   - Редактор: Save, Cancel, выбор Visual / Markdown / Diff; выход учитывает несохранённые изменения.
4. Не выводить неработающие кнопки. Старую неоднозначную New заменить единой New document. Сейчас New открывает создание отдельной страницы в каталоге текущего документа; это не создание раздела внутри текста.

## Создание

- Когда открыт каталог, создаём внутри него. Когда открыт документ или вложение — в его родительском каталоге. Для общих экранов по умолчанию корень книги. Сворачивание другой ветки стрелкой не меняет контекст создания.
- Диалог всегда явно показывает и позволяет выбрать Folder, затем Name и итоговый путь. Сначала проверяем имя, границы книги и существующие файлы; ничего не перезаписываем.
- New document открывает редактор нового Markdown. Файл появляется в Git после Save; Cancel не создаёт пустую страницу.
- New folder создаёт каталог с `.gitkeep`, поскольку Git не хранит пустые каталоги. Маркер скрыт в дереве и списке. Создание фиксируется в книге после подтверждения диалога; удаление последнего документа в будущем должно сохранять явно созданный каталог.
- Создание каталога требует собственного обработчика: проверка режима read-only, безопасного пути, конфликтов имён и согласованная операция записи/Git. Не обходить обычные ограничения сохранения Gollum.

## Метаданные и производительность

- В таблице каталога: Name, Type, Size (для файлов), Modified (последний commit, затронувший файл). Для каталогов сначала без вычисления общего размера; дату можно отложить до появления эффективного агрегата.
- Не возвращать чтение всех blob и отдельный git log для каждого пункта дерева. Метаданные получать только для открытого каталога, по возможности пакетно, кешировать по revision/path. Дерево сохраняет существующий лёгкий индекс.
- Тёмная/светлая темы используют общие цвета для дерева, панели, таблицы, просмотрщика и текущего редактора. По умолчанию системная тема; ручной выбор сохраняется в браузере.

## Порядок реализации после обсуждения

1. Общая верхняя полоса, хлебные крошки, унификация контекстных действий и устранение дублирующих кнопок.
2. Кнопки New document / New folder слева, явный выбор каталога, обработчик создания каталога.
3. Метаданные списка и кеширование; светлая/тёмная темы.
4. Docker deployment на текущем тестовом стенде, проверка создания/отмены/повторов/некорректных путей/read-only, отсутствие замедления навигации и просмотр пользователем.

Новые изменения приложения остаются без commit/push до подтверждения результата. Репозиторий тестовой книги допускает тестовые записи согласно AGENTS.md.

## Уточнение компоновки

По уточнению пользователя все основные действия перенесены в общий заголовок с иконками и английскими подписями. Вторая строка содержит путь, New document / New folder и доступные для текущего объекта действия History/Edit/Open original. Rename находится в заголовке экрана Edit и требует сначала сохранить изменения. Upload/Download убраны из общей панели. Дублирующих панелей над документом и кнопок создания над деревом больше нет.

Последнее уточнение: все кнопки заголовка — только иконки с подсказками, в одном ряду с поиском. Папка создания имеет плюс. Путь — узкая полоска ниже без горизонтальных линий. History одна: на Home открывает книгу целиком, на другом документе — его историю; внутри обеих страниц есть общий селектор Entire book / документ.
