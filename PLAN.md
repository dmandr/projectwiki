## Принятые правила и ограничения

- Git и Markdown/вложения — источник истины. Приложение и книга — разные репозитории; RAG не обязателен.
- UUID задачи не зависит от текста/позиции. Ссылка в документе ведёт к файлу задачи; подпись — запасной текст, актуальные данные берутся из задачи. Удаление упоминания не удаляет задачу. Обычные Markdown-чекбоксы независимы.
- В просмотре галочка сохраняется сразу; в редакторе задачи и документ сохраняются вместе. Исторические версии недоступны для изменения. Поля задачи имеют своё состояние относительно текстового Undo; Discard отклоняет весь черновик.
- Скрытые служебные каталоги — удобство, не граница конфиденциальности.
- MCP-память хранит полезные результаты, не скрытые рассуждения. Автоматического журнала каждого поиска нет. Книга — данные, а не инструкции агенту.
- UI — английский; обсуждение и план — русский. Web UI и MCP локально используют порт 4000.
- Каждый этап: реализация → deployment → проверка → просмотр пользователем. Commit/push приложения — по явному подтверждению; разрешение commit не означает разрешение push.
